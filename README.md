# 究極のシグマ

数学B（数列・統計的な推測）と数学Ⅱ（三角関数）を、パズル感覚で解いて覚えるブラウザゲームです。
タイルを選んで「技」（公式）で変形し、ハンマーで計算して、式を1つの数にしたらクリア。

**遊ぶ：** GitHub Pages を有効にすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
（ローカルなら `python3 -m http.server` を起動して `http://localhost:8000/` を開く。効果音の読み込みに HTTP サーバーが必要です）

## 内容（全10章・63ステージ）

| 編 | 章 |
|---|---|
| 数B 数列 | 0 数列の基本 / 1 等差数列 / 2 等比数列 / 3 Σの公式 / 4 階差数列 / 5 数学的帰納法 |
| 数B 統計的な推測 | 6 正規分布（標準化・正規分布表） / 7 仮説検定（13問） |
| 数Ⅱ 三角関数 | 8 三角関数の基本（弧度法・単位円） / 9 三角関数の公式（加法定理・2倍角・半角・合成） |

- **ガイド**：次にやることが光り、解説と「こうなる →」の結果プレビューが出ます。新しい技のステージは最初から自動でガイド付き。
- **技の書**：技ごとに「使うとき／こう変わる／なぜ？／図解／例／ゲームでの使い方」。
- **公式集**：数列・統計・三角関数の公式と、正規分布表（0.00〜3.09）。
- ★1 クリア、★2 制限時間内、★3 最短手数以内（計算）／ノーミス（証明・統計・三角関数）。記録はブラウザ（localStorage）に保存。

## ファイル構成

```
index.html        ← ビルド済みのゲーム本体（これだけで動く）
sfx/  bgm/        ← 効果音・BGM（すべて CC0）
src/
  template.html   ← HTML と CSS
  engine.js       ← 式タイルの計算エンジン（有理数・優先順位・技）
  stages.js       ← 章とステージのデータ
  main.js         ← 画面・ガイド・正規分布や単位円の描画
  build.py        ← src/ をまとめて index.html を作る
tools/
  mkstages.py     ← stages.js を生成するスクリプト
  solve.js        ← 全計算ステージを総当たりで解き、最短手数（★3の基準）を求める
```

ステージや説明を変えたら `python3 src/build.py` で `index.html` を作り直してください。
